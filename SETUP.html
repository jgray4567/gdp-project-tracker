GDP Project Tracker

Load your real client & job data

One-time setup · about 5 minutes · your data lives in your own Google account. The board reads your Google Sheet live and writes changes back through a small script inside the same Sheet — the badge top-right flips from Demo Data to Live once connected.

1

Create the Sheet

  • Go to sheets.new and name it something like GDP Tracker Data.
  • Rename the first tab to Jobs, then add four more tabs. All five names exactly: Jobs · Time Log · Invoices · Clients · Dashboard
2

Paste the header rows

Copy each block and paste it into cell A1 of its tab — it spreads across the row. The board matches columns by these header names, so keep them exactly as written.

Jobs

Job #	Client	Project	Owner	Status	Start Date	Due Date	Health	Billable Amount	Notes

Time Log

Date	Client	Project	Person	Hours	Billable	Description	Job #

Invoices

Invoice #	Client	Issue Date	Due Date	Hours	Rate	Amount	Status	Paid Date	Description

Clients

Client	Primary Contact	Email	Phone	Rate	Payment Terms	Status	Tags	Last Activity	Outstanding

Dashboard

Key	Value
Next Job Number	7804
3

Share it as viewable-by-link

Share → under General access, change Restricted to Anyone with the link → role Viewer. The board pulls each tab as a plain CSV download, which needs this. Keep the link private — anyone holding it can view the Sheet.

4

Collect the IDs

  • Sheet ID — the long string in the Sheet URL between /d/ and /edit.
  • Each tab's GID — click a tab and read the end of the URL: #gid=12345. That number is that tab's GID. Grab it for Jobs, Time Log, Invoices and Clients.
5

Add the sync script

  1. In the Sheet: Extensions → Apps Script.
  2. Open apps-script.txt in a new tab, select all, copy, and paste it into the editor — replacing everything that's there.
  3. In the pasted script, change CHANGE_ME_TO_A_RANDOM_STRING to a random string you make up. That's your sync token — keep it private.
  4. Deploy → New deployment → gear ⚙ → Web app → Execute as Me → Who has access Anyone → Deploy. Approve the authorization prompts.
  5. Copy the Web app URL it shows you (it ends in /exec).
6

Connect the board

  1. Open the tracker and hit Settings (top right).
  2. Under Google Sheets Connection: paste the Sheet ID and the four GIDs.
  3. Under Sync Endpoint: paste the Web app URL into Sync Endpoint URL and your random string into Sync Token.
  4. Save. The badge flips to Live.
✓

Using it

  • Fastest data entry: type rows straight into the Sheet — the board reads them on refresh. Columns follow the header order.
  • From the board: add jobs and clients in the UI, then hit Sync Now to push changes up.
  • Status values (they place cards in board columns): Lead · In Progress · Review · Complete · Billed. Owner: Jon or Joy.
  • A connected tab with zero rows still displays demo content — put one real row in each tab and it clears.
Before setup: anything typed into the board resets to demo on refresh — don't enter real data until the Sheet is connected. Settings are stored per browser, per URL — when the board moves to its permanent address, paste the same six fields in once there.
